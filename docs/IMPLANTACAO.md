# Roteiro de implantação — Mardisa Care+

## Fase 1 — Preparação

- Definir responsáveis pelo projeto.
- Definir os status oficiais da OS.
- Definir quais evidências podem ser enviadas.
- Definir modelo do Check-up Digital.
- Definir canal oficial de comunicação.
- Validar regras internas de privacidade e segurança.

## Fase 2 — Piloto de 30 dias

Selecionar um grupo controlado de atendimentos.

Fluxo sugerido:

1. Abertura da OS.
2. Geração do identificador.
3. Envio do link/QR Code.
4. Atualização manual do status.
5. Registro de evidências quando necessário.
6. Entrega do veículo.
7. Contato pós-serviço.
8. Registro dos indicadores.

## Fase 3 — Medição

Comparar o período piloto com o processo anterior.

Perguntas:

- Houve redução de contatos para perguntar o status?
- O cliente compreendeu melhor as recomendações?
- A satisfação aumentou?
- Houve redução de falhas de comunicação?
- Houve melhora na aprovação dos serviços?
- O processo é viável para a equipe?

## Fase 4 — Escala

Se os resultados forem positivos:

- ampliar para mais OS;
- padronizar treinamento;
- automatizar notificações;
- avaliar integração com o sistema de OS;
- expandir para outras unidades/processos.

## Responsabilidades sugeridas

### Consultor
- abrir/acompanhar a OS;
- garantir comunicação com o cliente;
- disponibilizar evidências aprovadas;
- confirmar a entrega.

### Oficina/Técnico
- fornecer informações técnicas;
- registrar condições e recomendações;
- apoiar evidências.

### Pós-venda/Gestão
- acompanhar indicadores;
- avaliar satisfação;
- conduzir melhorias.

### TI/Responsável pelo sistema
- segurança;
- hospedagem;
- integração futura;
- controle de acesso.

## Regra importante

O piloto deve usar dados fictícios ou dados tratados em ambiente corporativo autorizado. Não publicar informações reais de clientes em um repositório público.
